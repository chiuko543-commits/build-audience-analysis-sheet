# 受眾分析試算表 Skill

`build-audience-analysis-sheet` 是一個 Codex skill，用來根據企劃資料與參考試算表，製作可直接用於群眾集資、公益、文化活動、品牌或產品行銷的受眾分析 Excel。

## 功能

- 讀取企劃簡報、PDF、網址與既有 Excel 範本
- 萃取問題、方案、急迫性、獨特性、信任與價值
- 建立「核心對象／機會對象／有感對象」受眾分層
- 撰寫心理與行為描繪、溝通切入點及觸及管道
- 規劃新客興趣測試、相似受眾與再行銷
- 保留參考試算表的欄位、色彩與版面邏輯
- 檢查資料依據、敏感身分 targeting、文字裁切與表格範圍

## 適用情境

- 群眾集資受眾分析
- 公益募款與非營利組織行銷
- 文化藝術節、展演與教育計畫
- 新產品或品牌活動的新客開發
- Meta 廣告受眾與溝通策略規劃

## 安裝

將此儲存庫放入 Codex 的 skills 目錄：

```text
~/.codex/skills/build-audience-analysis-sheet/
```

目錄中至少需要：

```text
build-audience-analysis-sheet/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    └── audience-framework.md
```

重新開啟 Codex 工作階段後，即可使用：

```text
$build-audience-analysis-sheet
```

## 使用範例

```text
使用 $build-audience-analysis-sheet，
根據這份企劃 PDF 與 Excel 範本製作受眾分析，
以拓展新客為主要目標，並加入 Meta 廣告興趣、
相似受眾與再行銷建議。
```

也可以直接提出自然語言需求：

```text
請按照我提供的受眾分析格式，
替這次群眾集資計畫製作受眾分析試算表。
廣告興趣要寫，我們需要新客。
```

## 預設試算表欄位

1. 受眾層級或大項分類
2. 族群
3. 心理描繪與行為
4. 溝通切入點
5. 觸及管道與廣告興趣測試

若使用者提供既有範本，skill 會優先沿用範本的結構與視覺格式。

## 受眾分層

### 核心對象

既有支持者、參與者、合作夥伴、創作者社群或高度相關的在地受眾。

### 機會對象

需求、職業、興趣或行為與專案問題及解法直接相關的新客。

### 有感對象

可能從價值觀、地方、家庭記憶、身分探索或鄰近議題產生共鳴的受眾。

## 廣告規劃原則

興趣詞會標示為「興趣測試」，代表應在實際廣告管理員中搜尋與驗證，而不是保證平台目前提供該選項。

skill 會區分：

- 興趣冷受眾
- 相似受眾
- 網站與社群再行銷
- 合作夥伴及社群擴散
- 適合各受眾的素材形式

不應根據行為推測族群、宗教、健康狀態或其他敏感身分。使用捐款者、顧客或活動名單時，應確認具備必要權利、同意與合法依據。
